# LiteVer

Clear PowerKeeper data and tame Joyose **without root** (via Shizuku) for Xiaomi/POCO/Redmi. Basically, it's a little something for gaming to stop the OS from throttling your FPS >:)

## Requirements
- Android 11+
- [Shizuku](https://shizuku.rikka.app)

## Tested on
- HyperOS 2 (Android 14)
